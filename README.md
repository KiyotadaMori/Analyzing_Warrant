# WarrantScore Claim/Evidence/Warrant Data

This folder contains an Excel workbook for external inspection of the
claim/evidence/warrant data used in the WarrantScore reproduction analysis.

## File

- `WarrantScore_claim_evidence_warrant_data.xlsx`

## Workbook Sheets

- `SubstanReview`
- `RottenReview`
- `ReviewGuard_Orig_Elongated`
- `ReviewGuard_Sufficient`
- `ReviewGuard_Deficient`

The workbook also includes `README` and `Sheet_Index` worksheets.

Original data-column names are preserved for traceability.
